移民身份 ≠ 税务身份

身份与税务居民

在新加坡，「移民身份」和「税务居民」是两套判定：准证、永久居民（PR）和公民由人力部（MOM）与移民与关卡局（ICA）管，是不是税务居民由税务局（IRAS）按居住事实和天数判。公民和 PR 要「通常居住在新加坡、只是暂时离境」才算税务居民；外国人则看上一日历年在新停留或工作是否满 183 天，另有连续三年、跨两年等行政口径。所以拿到 PR 不等于永远是税务居民，没有 PR 也可能是税务居民。税务居民在新加坡按累进税率就新加坡所得纳税，境外来源收入汇入新加坡一般免税；外籍和 PR 雇员离职、外派或离新超过三个月，由雇主办理税务清算（IR21）。本页只陈述官方原文，个案请交新加坡税务师与律师。

与中国身份的衔接

  • 中国来源收入：新加坡税务居民的境外来源收入汇入新加坡免税（经新加坡合伙取得的除外），存入新加坡银行账户一般也不征税；属新加坡受雇附带的境外工作、为外国雇主在新工作等官方列明情形才在新加坡纳税。中国一侧的税务居民判定见跨境图谱 CN-01。 [原文↗] [原文↗]
  • 两地都是居民时的加赛：按中新税收协定第四条，个人同时是两国居民的，先看在哪一国有永久性住所；两国都有的，看个人和经济关系更密切的一国（重要利益中心）；仍定不了的看习惯性居处，再看国籍，最后由两国主管当局协商解决。 [原文↗]
  • 在中国内地停留 183 天：按协定第十五条，新加坡居民在中国受雇取得的报酬，同时符合三项条件的只在新加坡征税：在任何十二个月内在华停留累计不超过 183 天；报酬由非中国居民雇主或代表该雇主支付；报酬不由雇主在华的常设机构或固定基地负担。 [原文↗]
  • 在中国已纳的税：按协定第二十二条，新加坡居民从中国取得、依协定可在中国征税的收入，新加坡按本国抵免规定，允许以已缴中国税款抵免该笔收入的新加坡税款；这只在该收入在新加坡也须纳税时才有意义，抵免额不超过对应的新加坡税款。 [原文↗] [原文↗]
  • 中国税务居民的新加坡账户：中国在新加坡 2025 年 CRS 申报管辖区名单内：新加坡金融机构会把中国税务居民的账户资料报 IRAS 转交中国。同时是两地税务居民的，开户自我证明须把所有税务居民地和各地税号都填上。 [原文↗] [原文↗]

03 · 身份维护

准证、永久居民、公民与税务事项分开看

管理身份

在新加坡，「移民身份」和「税务居民」是两套判定：准证、永久居民（PR）和公民由人力部（MOM）与移民与关卡局（ICA）管，是不是税务居民由税务局（IRAS）按居住事实和天数判。公民和 PR 要「通常居住在新加坡、只是暂时离境」才算税务居民；外国人则看上一日历年在新停留或工作是否满 183 天，另有连续三年、跨两年等行政口径。所以拿到 PR 不等于永远是税务居民，没有 PR 也可能是税务居民。税务居民在新加坡按累进税率就新加坡所得纳税，境外来源收入汇入新加坡一般免税；外籍和 PR 雇员离职、外派或离新超过三个月，由雇主办理税务清算（IR21）。本页只陈述官方原文，个案请交新加坡税务师与律师。

资料核对 2026-09-25 · 下次复核 2026-12-24

  1. 临时身份 · 访客准证与入境要求

    移民身份：中国大陆普通护照短期访问无需另办签证；入境时获发的电子准证（e-Pass）决定实际可停留期限，延长停留须另行申请；除少数情形外，旅客须在抵达前三天内（含抵达当日）提交 SG Arrival Card。

    税务事项：税务上不看入境身份，看停留与工作天数：外国人上一日历年在新停留或工作满 183 天，即为该课税年度的税务居民；非居民一年内在新受雇 60 天或以下的短期受雇收入免税（董事、公众艺人、专业人士除外）。

    查看本项依据与详细说明 →

  2. 临时身份 · 学生准证（Student's Pass）

    移民身份：须已获新加坡认可教育机构录取修读全日制课程，兼读、夜间或周末课程不符合资格；已持有效长期探访准证或家属准证的人修读全日制非宗教类课程，无需另办学生准证。

    税务事项：学生准证本身不决定税务身份：外国人上一日历年在新停留或工作满 183 天，或连续三年在新停留或工作，即按税务居民处理；不满足的为非居民。

    查看本项依据与详细说明 →

  3. 长期居留 · 工作准证（就业准证 EP、S准证、PEP、ONE Pass 等）

    移民身份：以就业准证为例，须先达到按年龄分级的最低合格月薪，再通过积分制 COMPASS 评估（须达 40 分，豁免情形除外）；EP 或 S准证持有人可按 ICA 所列类别申请新加坡永久居民。

    税务事项：持有有效期至少 1 年工作准证的外国人也会被当作税务居民；但停止受雇办理税务清算时，会按居民规则重新审查，在新停留不足 183 天的视为非居民。清税程序适用于所有工作准证持有人，包括 PEP 持有人。

    查看本项依据与详细说明 →

  4. 长期居留 · 家属准证（Dependant's Pass）

    移民身份：EP 或 S准证持有人（固定月薪至少 $6,000）可为合法配偶及未满 21 岁未婚子女申请；家属准证持有人获聘时，雇主可为其申请 EP、S准证或 DP-Work Permit。

    税务事项：家属本人是否税务居民，按本人在新停留或工作的天数套用外国人规则（183 天、连续三年等）。要不要报税看本人收入：一般上一日历年总收入超过 $22,000 须报税，有新加坡收入的非居民不论金额都须报税。

    查看本项依据与详细说明 →

  5. 永久居留 · 新加坡永久居民（PR）

    移民身份：PR 出境须持有效再入境许可（REP）；自 2025 年 12 月 1 日起，离境时没有有效 REP，或 REP 在境外失效后 180 天内未申请续签、申请被拒，都会丧失 PR 身份。

    税务事项：IRAS 对 PR 的判据是「通常居住在新加坡、只是暂时离境」，看的是居住事实，不是身份证本身。PR 雇员停止受雇、外派海外或计划离新超过三个月，雇主一般同样要为其办理税务清算（IR21）。

    查看本项依据与详细说明 →

  6. 公民 · 新加坡公民

    移民身份：持有 PR 满 2 年且年满 21 岁可申请入籍，另有婚姻、就学、年长父母等类别；16 至 60 岁获批者须完成「新加坡公民之旅」，获批的男性须履行国民服役义务。

    税务事项：公民与 PR 用同一条判据：通常居住在新加坡、只是暂时离境的为税务居民，按 0% 至 24% 的累进税率就新加坡所得纳税；国籍本身不改变境外来源收入汇入新加坡一般免税的规则。

    查看本项依据与详细说明 →

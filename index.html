移民身份 ≠ 税务身份

身份与税务居民

在新加坡，「移民身份」和「税务居民」是两套判定：准证、永久居民（PR）和公民由人力部（MOM）与移民与关卡局（ICA）管，是不是税务居民由税务局（IRAS）按居住事实和天数判。公民和 PR 要「通常居住在新加坡、只是暂时离境」才算税务居民；外国人则看上一日历年在新停留或工作是否满 183 天，另有连续三年、跨两年等行政口径。所以拿到 PR 不等于永远是税务居民，没有 PR 也可能是税务居民。税务居民在新加坡按累进税率就新加坡所得纳税，境外来源收入汇入新加坡一般免税；外籍和 PR 雇员离职、外派或离新超过三个月，由雇主办理税务清算（IR21）。本页只陈述官方原文，个案请交新加坡税务师与律师。

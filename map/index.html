新加坡身份体系地图

从访客、学生这类临时身份，到工作、创业与家属准证，再到永久居民（PR）与公民。准证、永久居民和公民由人力部（MOM）与移民与关卡局（ICA）管。箭头表示常见的研究路径，不代表自动转换或保证获批；每一步的条件都要单独核对。

阶段一

临时身份与准证

访客入境时获发的电子准证（e-Pass）决定实际可停留期限；学生准证须获全日制录取；工作与家属准证（EP、S Pass、ONE Pass、PEP、EntrePass、家属准证、长期探访准证）各有薪资、配额或担保人条件。

从 EP 看起 →
阶段二

永久居民（PR）

ICA 所列可申请类别包括公民或 PR 的配偶与子女、公民的年长父母、EP 或 S Pass 持有人、通过全国性考试的学生，以及全球投资者计划（GIP）投资者；ICA 综合考虑家庭纽带、经济贡献、学历、年龄、家庭状况及居住年限。PR 出境须持有效再入境许可（REP）。

看 PR 条件 →
阶段三

公民

持有 PR 满 2 年且年满 21 岁可申请入籍，另有婚姻、就学、年长父母等类别；16 至 60 岁获批者须完成「新加坡公民之旅」，获批的男性须履行国民服役义务。

读书学生准证（Student's Pass）须获新加坡认可教育机构录取修读全日制课程，兼读、夜间或周末课程不符合资格；在新就读并通过至少一项全国性考试的学生是 PR 可申请类别之一。看学生准证 →

常见研究路径

EP 或 S Pass → PR → 公民

EP 或 S Pass 持有人是 ICA 所列 PR 可申请类别之一，PR 申请一般处理时间为 6 个月；持有 PR 满 2 年且年满 21 岁可申请入籍，一般处理时间为 12 个月。

核 EP →
学生准证 → 通过全国性考试 → PR → 公民（就学表现类别）

在新居住超过 3 年（其中至少 1 年为 PR 身份）、在新就读并已通过至少一项全国性考试的 PR 学生可申请入籍；以外籍学生身份获批 PR 的男性须履行国民服役义务。

核学生准证 →
全球投资者计划 → PR → 第 5 年续 REP

获原则批准后须在 6 个月内完成投资；取得 PR 后首次核发的 REP 有效期为 5 年，须在第 5 年满足对应投资选项的续签条件方可续期。

核 GIP →
公民配偶：PR → 与公民结婚满 2 年 → 公民

公民或 PR 的配偶是 PR 可申请类别之一；持有 PR 满 2 年、且与新加坡公民结婚满 2 年的，由公民配偶担保申请入籍。

核入籍条件 →

地图只负责把路径摆清楚。自 2025 年 12 月 1 日起，PR 离境时没有有效 REP，或 REP 在境外失效后 180 天内未申请续签、申请被拒，都会丧失 PR 身份。某个类别是否在受理、你是否符合条件、门槛数字今天是多少，请以签证页、关键数字 与 政策动态 的官方原文核对；拿到 PR 不等于成为税务居民，见 身份与税务居民。

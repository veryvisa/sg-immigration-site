先看结论

EP 或 S Pass 持有人为不符合 DP 资格的家属（如事实婚姻配偶、成年残疾子女、继子女、父母）申请的长期探访准证。

主要适合：EP 或 S Pass 持有人的事实婚姻配偶、残疾成年子女、未满21岁继子女，或符合条件的父母。这不是个案资格或获批结论。

硬条件与官方依据

项目当前已核对的要点原文
担保人条件担保人须持有 EP 或 S Pass，固定月薪须达至少 $6,000（按担保人个人薪资计算），并由信誉良好的新加坡注册公司担保。
Ministry of Manpower (MOM) ↗（论坛解读）
可申请家属范围包括事实婚姻（common-law）配偶、未满21岁未婚继子女、未满21岁未婚残疾子女，以及担保人固定月薪达 $12,000 以上时的父母。
Ministry of Manpower (MOM) ↗（论坛解读）
与 DP 的区分如申请人已合法结婚或有亲生子女，应改申请 Dependant's Pass 而非 LTVP。

ICT 身份除外以 WTO GATS 或相关自由贸易协定下 ICT 身份申请的 EP 持有人，其家属原则上不合资格申请 LTVP，除非相关协定另有明确规定。

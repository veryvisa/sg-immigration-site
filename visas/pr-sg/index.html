新加坡永久居民（PR）

Singapore Permanent Resident (PR)

受理中官方确认最后核对 2026-09-25下次复核 2026-12-24

先看结论

ICA 核发给获批永久居留资格的外籍人士的居留身份，须持有效再入境许可（REP）方可出境后维持该身份。

主要适合：新加坡公民/PR 的配偶及子女、新加坡公民的年长父母、EP/S Pass 持有人、在新就读并通过全国性考试的学生，以及 GIP 投资者。这不是个案资格或获批结论。

硬条件与官方依据

项目当前已核对的要点原文
六类申请资格可申请类别包括：新加坡公民或PR的配偶；未满21岁且在合法婚姻内出生或被新加坡公民/PR合法领养的未婚子女；21岁以上新加坡公民的年长父母；EP或S Pass持有人；在新就读并已通过至少一项全国性考试（PSLE、'N'/'O'/'A' 水准或综合课程）的学生；以及透过全球投资者计划（GIP）申请的外国投资者。

中国申请人注意

官方页面没有针对中国大陆出生或国籍申请人的特别规定。

通往永居或入籍的路径

持有 PR 满 2 年且年满21岁（或与新加坡公民结婚满2年、或作为新加坡公民子女等其他类别）可依 ICA「成为新加坡公民」页面申请入籍。
